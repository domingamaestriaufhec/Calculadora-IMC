# 📱 Calculadora Sencilla de IMC

Una calculadora web sencilla, rápida y moderna para conocer tu **Índice de Masa Corporal (IMC)**.

## 🚀 Cómo usar
1. Abre [index.html](index.html) en tu navegador.
2. Ingresa tu peso en kilogramos (kg) y tu altura en centímetros (cm).
3. Haz clic en **Calcular IMC** para ver tu resultado y clasificación.
