📘 Explicación de la Programación

Estructura, algoritmos y tecnologías utilizadas

1. Estructura HTML (Semántica)

Construye la interfaz mediante etiquetas semánticas (<form>, <input>, <button>), incorporando validación nativa de tipos y límites numéricos (min, max, step).

2. Lógica JavaScript (Algoritmo)

La lógica se ejecuta en 4 pasos fundamentales:

  • Captura: Escucha el evento submit y previene la recarga con e.preventDefault().
  • Conversión: Convierte la altura de centímetros a metros: altura(m) = cm / 100.
  • Fórmula Matemática: Aplica el cálculo estándar: IMC = peso / (altura * altura).
  • Clasificación: Evalúa rangos de la OMS mediante condicionales:
    • < 18.5: Bajo peso
    • 18.5 a 24.9: Peso normal
    • 25.0 a 29.9: Sobrepeso
    • ≥ 30.0: Obesidad

3. Diseño CSS (Estilos y Reactividad)

Implementa una paleta oscura moderna con Flexbox / CSS Grid, bordes sutiles y estados dinámicos para retroalimentar visualmente al usuario según su resultado.
